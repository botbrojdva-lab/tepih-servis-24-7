# Tepih Servis 24/7

Static multi-page marketing website for a Serbian deep-cleaning service company. The project is built with plain HTML, CSS, and JavaScript (no backend and no build tools).

## Project structure

- `index.html` – Home page
- `onama.html` – About page
- `usluge.html` – Services page
- `kontakt.html` – Contact page
- `css/style.css` – Shared styles
- `js/script.js` – Shared interactions

## Run locally

This is a static site, so you can:

1. Open `index.html` directly in your browser, or
2. Serve the folder with any static server (for example `python -m http.server`) and open the local URL.

## Important before going live

In `kontakt.html`, replace `YOUR_FORM_ID` in the Formspree action URL with your real Formspree form ID from https://formspree.io/.
